# 探索词典 · ExplorerDict

把「划词 → 原文阅读 → 资料整理 → 带依据的问答 → 学习计划」连成一条**本地优先**的学习链路。
Windows 桌面应用：原生划词取词 + 本地阅读工作区，词库、文章、笔记、计划与索引都保存在本机。

- 划词只在用户明确点击「解释并记录」后才调用模型；面板展开、标注、检索索引均在本机完成。
- 模型 API 由使用者自备，密钥经 Windows DPAPI 加密后仅存本机，仓库不含任何密钥与个人数据。

## 背景

课程资料、论文与长文档散落在浏览器、PDF 与办公软件里。常见的划词工具停在「即查即走」：解释没有沉淀，回答找不到原文依据，读到的东西也很难变成自己的笔记和计划。

探索词典要解决的不是「查一个词」，而是把**看到 → 读懂 → 记下 → 用起来**连成一条可回头的链路，并保证每个结论都能回到原文。

## 设计理念

1. **本地优先**：词库、文章、笔记、索引与计划默认都在本机；只有显式发起的解释/问答才联网。
2. **原文为凭**：问答与导图节点必须能定位到原句；引用不合法时拒绝写入，而不是「看起来像答案」就收下。
3. **人决定边界**：划词本身不落库、不联网；点「解释并记录」才产生数据，删除就是删除。
4. **过程可核验**：需求、实现、测试、验收记录、Prompt 链与提交历史互相对应，能顺着任意一条线复查。

## 特点

- **跨应用取词**：在浏览器、PDF、WPS/Word 等前台窗口划词即可取到上下文与来源；不注入进程、不模拟按键。
- **词条带出处**：每条词都有上下文、来源标题与链接，可标签、合并、拆分、多格式导出。
- **阅读工作区**：原文标注（荧光/下划线）、随文心得、引用跳回原文、比较阅读、标记读完。
- **全文导图**：独立阅读 → 生成 → 复核三阶段；节点可查原句，失败草稿与合格图分开保存。
- **学习闭环**：主题资料库、计划与对话式规划、今日概览、探索统计、内容管理。
- **可审计**：本地 SQLite 存储 + 验收记录 + 细粒度提交历史，便于复查每个功能的来路。

## 适用场景

- 课程教材、论文与技术文档的精读：边读边标注，读完能回到原句复习。
- 专业术语积累：把词、上下文、出处一起沉淀，而不是只记一条释义。
- 资料库问答与比较阅读：围绕自己的资料提问，答案带可点击的依据。
- 备考与阅读计划：把「读什么、读多久、读到哪」变成可勾选的安排。

## 边界

- 它**不是**「划词即出翻译」的速查词典；不点击就不会产生数据。
- 当前仅支持 Windows；模型服务需使用者自备（OpenAI 兼容接口）。
- 不承诺任何游戏/反作弊兼容性，也不做进程注入或输入模拟。
- 离线能力限于本地检索、阅读与整理；解释与问答需要模型服务。

## 快速开始

**直接使用**：Windows 10/11 下运行 `探索词典.exe`（需与 `_runtime` 同目录）。阅读工作区入口在托盘菜单或主界面「阅读工作区」。

**从源码运行**：

```powershell
python -m venv .build-env
.build-env\Scripts\activate
pip install -r requirements-reading.txt
python bootstrap.py
```

- 运行环境：Windows 10/11、Python 3.12+（开发与验收使用 3.14.5）。
- 首次启动会引导配置模型服务（OpenAI 兼容接口），也可以先跳过、仅使用本地功能。
- 数据目录默认在项目内 `data/`，可在设置中更改存储位置。

**运行测试**：

```powershell
python -X utf8 -m unittest discover -s tests -t .
```

## 10 分钟复现

干净机器从克隆到启动：

```powershell
git clone https://github.com/bsk865/ExplorerDict.git
cd ExplorerDict
powershell -ExecutionPolicy Bypass -File scripts\setup-repro.ps1
.build-env\Scripts\python.exe bootstrap.py
```

脚本会建虚拟环境、按 [requirements.txt](requirements.txt) 安装依赖、下载并校验离线向量模型（SHA-256），最后跑全量测试；可用 `-SkipModel` / `-SkipTests` 跳过对应步骤。完整步骤、环境变量模板、验证清单与常见问题见 **[10 分钟复现指南](docs/复现指南.md)**。

## 架构

```
bootstrap.py / desktop_entry.py   ← 启动与单实例、浮窗/主界面
app/                              ← 原生层：取词、UIA 桥、解释/问答服务、SQLite、Tk 界面
  ui/                             ← 主界面、浮窗、设置、导图与导出
app/workspace_server.py           ← 阅读工作区的本地 HTTP 服务（仅回环）
web/                              ← 阅读工作区前端（原生 JS，无框架依赖）
models/ + app/local_embeddings.py ← 离线向量模型与检索
tests/                            ← unittest 全量用例
```

- **三层边界**：原生壳负责取词与本地能力；本地 HTTP 服务提供阅读工作区接口；前端只经本机回环访问。
- **数据**：`explorer_dict.sqlite3`（词条/设置/密钥密文）与 `reading_workspace.sqlite3`（文章/笔记/计划/索引）分离存放，均在 `data/` 下。
- **模型调用**：统一的 OpenAI 兼容客户端，带超时、有限重试与请求归属校验；回答只引用检索到的片段，引用不合法时拒绝落库。
