# 探索词典 · ExplorerDict

**让每一次阅读，都能成为下一次探索的起点。**

探索词典是一款连接内容发现、原文阅读与知识整理的 Windows 桌面应用。收集一篇新闻、导入一份文档，在原文旁提问、翻译或理解图表，再把理解留下为笔记、导图与后续学习安排。文章、问题、引用和自己的心得保持联系，下次打开时可以接着探索。

## 先看六个核心体验

| 体验 | 可以完成的事 |
| --- | --- |
| **读到哪里，就问到哪里** | 打开文章直接提问，在原文旁继续追问；全库问答查阅已入库资料，新增文章自动纳入 |
| **回答能够回到原句** | 查看本次材料的引用，返回文章并定位原句；多篇资料分别保留依据 |
| **译文真正属于这篇文章** | 自选源语言和目标语言，对照阅读；语言、译文和进度按文章分别保存 |
| **图表与结构也能进入理解** | 框选图片提问，选择正文或图文导图，查看节点与关系的原文依据 |
| **读完以后，成果留得下来** | 保存标注与心得，编辑导图，导出阅读笔记、PNG、SVG 或结构化 Markdown |
| **兴趣能够接上后续行动** | 发现新闻与论文、获取全文、整理主题，再为相关资料安排学习任务 |

## 为什么围绕阅读来设计

阅读可以从一条资讯卡片、一份 PDF、一个搜索结果或一次 AI 对话开始。读者仍要面对具体的问题：值得精读的内容散在不同入口；遇到术语需要来回切换；得到回答后要找到依据；读完之后还需要留下自己的理解。

AI 可以辅助解释、跨语言阅读、图文理解和结构整理。探索词典将这些能力放回文章与资料库：问题关联上下文，回答保留引用，译文和导图随文章保存，个人笔记与原文分别呈现。用户能够继续核对、修改和积累。

关于信息入口、AI 摘要与来源查阅的公开观察，见[项目介绍中的背景分析](docs/项目资料/项目介绍.md#ai时代阅读入口正在改变)及其中的 Reuters Institute、Pew Research Center 资料。

## 一条完整的探索路径

以持续了解一个技术主题为例：

1. **发现线索**：选择兴趣和新闻、论文来源，浏览最新内容，收藏值得跟进的文章。
2. **取得全文**：从公开链接获取全文，或导入自己的 PDF、DOCX 和文本，归入主题资料库。
3. **边读边问**：围绕原文提问并核对引用；翻译外文，框选图表，再与其他资料比较。
4. **整理理解**：标注关键句、记录心得、编辑导图，导出本文章的阅读成果。
5. **继续学习**：描述目标和可用时间，确认关联资料与任务，在后续阅读中接着推进。

这些动作沿用文章、版本、来源和原文位置。各功能形成的结果有自己的归属，切换文章后仍可分别恢复。

### 发现与全文：从线索走到可阅读的资料

新闻、科技社区、科学传播与开放论文集中浏览。用户可以管理 RSS/Atom 来源、填写兴趣、屏蔽关键词，也可以收集公众号或浏览器中的公开文章链接。封面来自原站或订阅提供的资源。

更新分别统计新增和修改，“本次更新”集中展示变化。选择“获取全文并加入资料库”后，正文进入阅读与检索；摘要单独标识，公开论文可保留取得的 PDF 原件。[发现与订阅](docs/发现页.md)

### 问答与翻译：把理解放在阅读现场

“问本文”聚焦正在阅读的文章；资料库问答用于跨资料查阅与比较。关键词和本地向量检索共同查找片段，回答携带本次引用，点击即可回到对应文章和原句。个人笔记可以参与检索，并保留其个人内容身份。

翻译位于文章工具栏，支持源语言与目标语言选择、原文译文对照、长文分段、停止和继续。不同文章分别保存语言、草稿、译文与进度。[翻译操作](docs/翻译.md) · [多篇公开资料问答案例](docs/screenshots/multi-public-rag-20261024/README.md)

### 导图与笔记：把理解变成可复用的成果

导图从正文或图文资料开始研读、组织与复核，节点和关系保留原文依据。生成后仍可修改文字、新增或删除分支、调整上级与关系、拖动布局、撤销或恢复；个人补充带有标记。长图可以分层浏览，导出仍保留完整内容。

阅读笔记把本文章的原文、标注、心得、问答与引用、译文组织为 Markdown。内容管理可以搜索先前记录，再回到关联来源。[导图操作](docs/导图.md) · [笔记导出](docs/阅读笔记.md) · [内容管理](docs/内容管理.md)

## 适合怎样的阅读

- **课程与自主学习**：导入课件和讲义，围绕概念追问，保留原句、标注与心得，安排复习。
- **论文与技术研读**：取得全文、查看图表、对照翻译，比较多篇文章并沿引用核对。
- **专题探索**：从新闻和社区内容发现问题，将不同来源归入主题，持续跟进相关资料。
- **日常积累**：在外部应用划词保存线索，回到主界面取得全文并继续整理。

## 快速开始

当前版本 **1.0.20261025.3**，支持 Windows 10/11 x64。

1. 从 [Releases](https://github.com/bsk865/ExplorerDict/releases/tag/v1.0.20261025.3) 下载 `ExplorerDict-Stage-1.0.20261025.3-Windows-x64.zip`，**完整解压后再启动**。
2. 双击 `探索词典-原生版.exe`。运行环境与本地向量模型随包提供，**无需另装 Python**；移动软件时保留整个程序目录。
3. 导入一篇自己的资料，尝试阅读、查找、标注和随文笔记。
4. 需要 AI 功能时，在设置中填写自己的模型接口、模型、推理强度与 API 密钥并保存。图片理解还需检测模型的图片输入能力。
5. 打开“问本文”并核对一次引用，再尝试翻译、导图或笔记导出。

| 使用条件 | 相关功能 |
| --- | --- |
| 本地即可开始 | 已有文件导入、阅读、标注、笔记和保存记录查看；本地检索使用随包模型 |
| 需要网络来源 | 订阅更新、原站封面、公开网页和论文获取、天气 |
| 需要自己的模型服务 | 问答、翻译、导图和规划；图文任务需要对应的图片能力 |

当前以免安装 ZIP 分发。来源更新、文章取得和模型结果取决于网络、来源访问条件及所选服务。[完整使用指南](docs/使用指南.md) · [常见问题](docs/使用指南.md#常见问题)

## 主界面与浮窗如何协作

| 入口 | 主要用途 |
| --- | --- |
| 悬浮窗 | 在外部应用获取选区、上下文和来源，承接即时解释与探索线索 |
| 原生主界面 | 完成发现、全文阅读、问答、翻译、导图、笔记与学习规划 |

两者共用资料目录、模型配置、配色和明暗模式，按各自刷新周期读取持久化设置。保存的资料可由另一入口继续使用，页面与临时编辑状态由各自窗口管理。六套配色贯穿两个入口，共享主题控件用于表单、确认和文件选择。[外观与资料操作](docs/使用指南.md#浮窗主题与资料保存)

## 资料保存与模型请求

资料默认保存在程序目录的 `data` 中，可在设置里查看或更改保存位置。兴趣分析、本地检索和记录保存在本机；使用联网模型时，相关问题、文本或图片会发送给你配置的服务。模型和推理强度由你选择。

API 密钥使用 Windows DPAPI 保存，换电脑后重新填写。备份前完全退出主界面与浮窗，再复制整个资料目录；迁移操作在应用完全退出后生效，原目录保留。分享程序时使用 Releases 中的干净包。[数据与模型说明](docs/信息存储与上下文说明.md)

## 系统如何实现

![探索词典架构与阅读数据流](docs/images/architecture.png)

原生主界面采用 **Python / PySide6**，浮窗通过 Windows 辅助功能接口取得选区与上下文。共享业务服务连接文章、会话、译文、导图与计划；**SQLite**、附件和版本信息保存阅读资料及其关联。

资料问答使用关键词检索与 **multilingual-e5-small / ONNX Runtime** 本地向量检索，融合召回后选择依据，再交给生成模型回答。本地向量编码与联网生成分别承担检索和理解任务。引用、文章版本和结构化结果由业务规则继续核对。

模型请求管理处理前台优先、相同请求合并、时间预算、临时错误重试和停止。翻译与导图按输入身份保存检查点，使有效进度能够在中断后继续。[19章技术设计](docs/项目资料/技术文档.md) · [技术PDF](docs/项目资料/技术文档.pdf)

## 开发与运行

开发环境为 **Windows 10/11 x64、PowerShell 5.1+、CPython 3.14 x64**。准备脚本创建 `.build-env`，安装固定依赖、下载并校验向量模型、编译 UIA 辅助库。

```powershell
git clone https://github.com/bsk865/ExplorerDict.git
cd ExplorerDict
powershell -ExecutionPolicy Bypass -File scripts/setup-repro.ps1 -SkipTests
.build-env/Scripts/python.exe native_desktop.py
```

## 当前范围与后续方向

当前程序功能基线对应 `3049488`，版本为 **1.0.20261025.3**；主分支继续维护源码准备与项目文档。

主分支已追加主题卡片拖放和跨应用取词修复，现有下载包尚未重新打包。WPS 划选的运行权限处理见[常见问题](docs/使用指南.md#常见问题)。

- **公开内容接入**：支持 RSS/Atom、公开链接与可访问全文。公众号采用公开文章链接，浏览器通过复制链接接入；当前未提供账号登录或浏览器扩展。
- **复杂资料与模型**：扫描页、图文和长材料的表现与所选模型及输入质量有关；可查看原文、调整输入并保留已有结果。
- **持续优化**：继续完善长资料、长时间跨应用使用、窗口适配与升级体验。安装器系统注册权限与发布者签名仍在后续完善范围内。
