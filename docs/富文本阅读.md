# 富文本阅读

网页和文档保留原来的富文本块。阅读、文章翻译、关键词检索、语义检索、探索词条和带引用心得使用同一份正文视图，避免出现文章看得见、检索不到，或选中文字无法保存的问题。

已保存的文章版本、HTML、标注位置和历史问答引用保持原样。打开旧文章时计算正文视图；不因读取重写原始文章。旧检索缓存会重新建立，语义索引重建前不会使用旧正文产生的引用。

翻译仍在文章工具栏中。每篇文章分别保存语言、草稿、译文与任务，切换文章不会带入另一篇译文。主界面中保存的词条同步到浮窗时，携带相同的正文上下文。
