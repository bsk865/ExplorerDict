# 原生桌面迁移

目标：保持探索词典的功能、设计语言和既有资料，迁移为不加载 Qt WebEngine、不启动浏览器、不需要本地 HTTP 接口的原生桌面应用。最终安装包携带所需运行环境，用户无需安装 Python。

## 迁移原则

- 用户最新要求（2026-10-23）：完全复刻旧版界面，不随意更换显示；保留原有折叠区域及默认状态，空间布局、颜色和设计感以旧版为准。仅“使用相同配色”和“功能存在”不能作为界面迁移完成的依据。
- 视觉基准是 `web/index.html` 按实际顺序加载所有 CSS/JS 后的最终界面，不能只依据早期 `workspace.js` 中被后续脚本覆盖的布局。当前原生侧栏、阅读栏、对话栏等存在简化重排，尚未通过旧版界面对照验收，需逐页还原。
- 对照时记录默认、展开、选中、加载、空状态与窄窗口状态；至少覆盖小探收起/展开、文章操作菜单、划选时才出现的标注栏、引用依据、规划偏好、已有笔记与请求详情。不可用常驻按钮或新弹窗随意替代旧版折叠入口。
- 保留原有阅读插画、小探形象、六套配色、明暗模式和紧凑侧栏；原生控件使用统一间距、明确选中状态、可调整阅读分栏。
- 复用 Workspace、WorkspaceStore、StudyHub 等业务模块，沿用两个 SQLite 数据库及版本与引用键。禁止用示例资料填充用户数据库。
- 当前正式安装包保留；原生版使用独立入口、构建目录和运行库，完成核验后才作为正式入口。
- 测试使用独立数据目录。原始现场在 artifacts/startup-incident/20261022-183548 中保全。
- 不能以“测试通过”替代真实安装包启动、页面显示和工作流验收；未迁移项保持明确记录。
