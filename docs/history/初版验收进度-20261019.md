# 初版验收进度与历史记录

2026-10-19 更新：初版 1 已部署，原桌面入口和新初版入口均指向 `探索词典-初版1.exe`。最新使用方式、证据和限制见 [初版使用与验收](初版使用与验收-20261019.md)。下文“尚未交付”“待打包”等为此前阶段记录，不代表当前部署状态。实际外部文档划选仍按用户先前约定留待用户现场确认，模型导图的拒绝／重试情况如实记录，不宣称任意材料都一次生成成功。

定位：学术文献多模态研读助手。原文是依据；主界面管理资料和深入研读，悬浮窗负责外部阅读中的划选、解释与追问。正式资料库保持空白，保留模型配置。

## 已实现并验证

- 本地原文分块检索（中文双字 / 英文词，BM25），回答绑定文章版本、段落、页码、原文片段与偏移；支持当前文章或整个资料库范围。
- 引用预览、回到原文、跨文章引用的返回入口；长段落引用突出显示检索片段。
- 没有引用或引用编号错误的模型回答会进行一次纠正；不能修复的回答不写入会话。
- 使用同一个已配置接口检测图片理解。实际测试模型配置为 `deepseek-chat`，接口报告 `deepseek-flash`，正确识别了随机测试图及 4 个蓝色圆形；不依据名称猜测能力。
- 实际模型从约 4 万字隔离测试材料末尾找到 83 摄氏度与 K17，并返回来源，超过旧有截取范围。
- `workspace_sync.py` 双向同步收藏词语、解释与追问，自动轮询；解释进入会话，不写入个人笔记。缺少全文的外部划选明确标作片段。
- 主界面刷新不会覆盖输入中的草稿；浮窗读取数据库外部变更后更新词卡与当前会话。
- 设置页保存模型配置后，两端读取同一个本机加密配置；旧主界面配置在首次同步迁移。
- 取消收藏 / 原生删除不会在下一轮同步复活；可以重新收藏；无变化的同步不反复改写原生数据库。
- 修复只有正文、没有关系文件的合法 DOCX 导入。

## 后续进展：图片检索与删除闭环

- `visual_index.py` 为图片和扫描页生成可搜索描述，以图片内容哈希及模型接口签名缓存。描述单独保存，不覆盖原文或改变原文版本。
- 提问时自动检测视觉能力、识别范围内未缓存的图片、检索相关图，再把最多三张相关原图与正文一起交给模型。没有实际发送的图片不进入本次回答引用。
- 图片描述明确标识为模型生成的检索材料，不能当原文引文。识别有进度和取消；成功的前序图片保留缓存，取消后的迟到结果不保存。
- “资料信息 → 识别图文内容”可提前识别；引用预览显示原图，局部图片引用有选区边框。
- “资料信息 → 删除资料”确认后删除当前资料和相连历史版本、对象、笔记/会话、导图尝试、检索索引及关联浮窗词条。仅清理不再被其他文章使用的图片及视觉缓存。
- 相关自动测试 36 项通过，覆盖缓存复用、模型切换、取消、空响应重试、共享图片删除、同步后不复活及 DOCX 导入。
- 真实接口验证：`%TEMP%/explorer-visual-live-qt_jm5r9/result.json`。两张无文字测试图自动识别，问题“哪页有蓝色圆形、有几个”正确返回第2页、4个，引用包含实际发送的第2页图片。首次出现安全连接错误，保持证书校验，复用同一隔离库重试成功。
- Playwright 已测试图片预识别入口、原图引用/跳转，以及删除确认、其余资料保留、同步后不复活；无页面运行错误。截图 `%TEMP%/visual-citation-desktop.png` 与 `visual-citation-mobile.png`。
- 以上仍是源码与隔离服务验收，不是新版包交付；桌面入口尚未更新。

## 后续进展：长文导图

- `long_article_map.py` 将超过 30,000 字的全文分成不超过 24,000 字的片段，相邻片段保留 500 字重叠。每段均执行既有独立阅读、生成、语义复核，不截取文章开头冒充全文。
- 已批准片段按原文版本、模型、片段内容、划选词与策略版本缓存。失败或取消不替换已有导图；重试复用已通过的片段。删除资料时也清理相应缓存。
- 分段导图采用明确的文章根节点、原文顺序分支和独立节点编号，保留每段原句、语义关系及全部划选词绑定。不编造跨段语义关系；界面明确标注分段研读。
- 删除旧的“三万字以内”前端限制与提示。补充“适应窗口”，展开/缩放时将根节点保持在视野中。跨段落引用可以定位到开始段落。
- 相关测试 41 项通过，包括无缺口全文覆盖、片段上限与重叠、合并后的引用/绑定、缓存复用、失败续做、取消不保存。
- 真实接口结果：`%TEMP%/explorer-long-map-live-tzif198p/result.json`。34,149 字隔离材料、2 段、15 个节点、4 条关系；通过复核，末尾“83摄氏度”保留，所有节点引用逐字存在于原文。
- Playwright 验证真实导图无节点重叠、SVG 导出与原文跳转；另以临时浏览器状态构造 151 节点密集树，节点无重叠、组织连线 150 条。语义关系在侧栏显示，不叠加交叉连线。无页面错误。
- 截图/导出位于 `%TEMP%/long-map-desktop.png`、`long-map-export.svg`、`dense-map-desktop.png`、`dense-map-mobile.png`；密集图只存在于浏览器测试状态，未保存至资料库。

## 后续进展：图文联合导图

- `multimodal_map.py` 将正文、图注、独立存储的图片识别描述按原文顺序交给导图流程，生成后的每个节点和关系绑定具体正文/图片来源。相同文字同时出现在正文与扫描页时保留两类依据。
- 图片生成的节点与关系额外经过一次实际原图视觉复核；识别描述本身不能代替原图验证。复核失败保留旧图、作废有争议的描述缓存，用户重试时重新看图。
- 原始文章块、文字和版本不被识别描述覆盖。前端明确区分图片识别依据，提供原图预览和原文位置跳转；关系导出也标明图片识别来源。
- 相关测试 46 项通过，新增覆盖纯图片导图、图文同句来源、视觉审核收到真实图像字节、审核失败保留原图及缓存作废。
- 真实接口：`%TEMP%/explorer-visual-live-qt_jm5r9/map-result.json`，纯图片资料生成 17 节点，两张图均单独审核通过，原文块未改写。首次安全连接失败后保留证书校验重试成功。
- Playwright 已验证视觉节点 → 图片依据预览 → 原图位置，页面无运行错误。截图 `%TEMP%/image-map-evidence.png`。
