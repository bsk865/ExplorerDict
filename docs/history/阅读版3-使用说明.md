# 阅读版使用说明

桌面入口：**探索词典 · 阅读版**。

## 阅读与提问

在“我的文章”中打开资料，也可以提取网页、导入文件或粘贴正文。

选中文字后点击“理解这一处”，小探会解释所选内容。点击图片可查看整图、框选局部并提问。回答下方的“原文”按钮返回对应段落。

需要在原网页或文档中阅读时，点击“在原文章中阅读”，打开桌面取词助手。

## 笔记与收藏

点击文章顶部的“笔记”记录整篇文章；选词或选图后，也可以在“我的笔记”中记录这一处。笔记自动保存，切换页面前也会保存。

“笔记与收藏”汇集文章笔记、词图笔记和主动收藏，可搜索并返回原文。旧版本的笔记仍可找到。收藏不会自动把小探的回答写成你的笔记。

“文章操作 → 导出笔记”可导出包含原文、图片、笔记和对话的阅读文档。

## 回答中断

回答过程中可以记笔记或停止回答。失败或停止后，问题保留在输入框中，可修改后发送，也可点击“重试”。

尚未设置模型时，提问会打开设置；图片理解未检测时，会引导到检测入口。检测使用设置框中当前填写的模型。

## 导图

首次进入导图页，点击“生成导图”。生成后可展开、缩放，点击节点查看原文依据。

超过 3 万字的文章目前显示文章目录，可直接跳转章节；尚不支持完整全文导图。长文问答参考有限正文，建议先选中相关内容。
