# 探索词典原生版：阶段交付

## 开始使用

打开`app/探索词典-原生版.exe`即可使用，无需安装Python或浏览器。请保留整个app文件夹，程序需要其中的运行库和美术资源。

也可以使用`ExplorerDict-Native-Stage-Setup.exe`安装到独立的原生版目录。安装器尚未签名，Windows如显示安全提示，请自行决定是否允许运行。

本交付不携带个人资料或API密钥。首次使用可在设置中配置模型，再导入文章测试；默认资料保存在该程序目录下。旧版程序与原资料备份保留。

## 本阶段变化

- 原生阅读空间及资料、标注、笔记、计划、统计、RAG问答等功能集中交付，保留原插画、配色与折叠入口。
- 返回时恢复阅读侧栏、查看对象、资料范围和草稿，Ctrl+Enter可发送问答。
- 问答预算默认跟随已确认的模型容量，最高1,000,000 tokens。已有较小预算保留，可在设置点击“使用模型上限”后保存。未知模型可填写服务商标注容量。
- 更改资料位置后，退出时复制资料并保留原目录，下次启动使用新位置。

这是供重新导入文章测试的阶段版本。完整界面对照、跨应用取词交互、复杂资料及多文档联网流程仍在继续验收。已完成与待办清单见`HANDOFF.md`。

## 交付文件

- `app/`：完整独立运行目录。
