# 翻译

在文章阅读工具栏点击“翻译”，选择源语言与目标语言后点击“开始翻译”。翻译是当前文章内的工具，侧栏不再单独设置翻译分区；“返回原文”可继续阅读。支持自动识别源语言，以及简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语和阿拉伯语。源语言明确时可交换语言方向。

阅读页的“翻译”默认带入文章文本，有文字选区时带入所选内容。原文和译文并排显示，均可滚动。每篇文章使用独立的原文草稿、语言选择、译文和翻译任务；切到另一篇文章不会显示上一篇的译文，后台完成也不会覆盖当前文章。返回原文章可恢复译文。已有译文时带入新的选区，先显示“载入新内容 / 忽略”，不直接覆盖。

发现页可以翻译摘要或简介，每条内容独立保存，并通过“收起翻译”回到预览。悬浮窗顶栏的“翻译”可带入当前选中文字，未选中文字时使用当前词条；主界面以内嵌工具打开，外部来源按来源标题隔离，不写入当前正在阅读的文章。来源标题缺失时按文本隔离，不猜测它属于哪篇文章。同来源已有原文或任务时显示“载入新内容 / 忽略”，不会清空草稿或停止任务。带入本身不调用模型。本地交接请求消费后删除，超过10分钟未处理则失效。

翻译沿用设置中的接口、模型、推理强度和加密密钥。只有点击“开始翻译”后才向模型发送原文；导航、选择语言和恢复页面不会发起请求。长文分段处理，显示进度。接口报告输出截断时，不把该段作为完成的译文保存。

原文、语言选项和译文保存在本机；切换文章不丢失任务，也不自动跳回原文章。停止或失败时保留已完成的段落，并标明未完成。支持复制译文、导出 Markdown 或纯文本。译文单独保存，不修改原文，也不自动加入 RAG。旧版公共草稿保留在本机，不自动归属到任何文章。

删除文章及历史版本时同步删除所属译文；延迟保存或退出应用不会把已删除文章的译文重新写回。其他文章、发现摘要和外部文字的翻译保留。
