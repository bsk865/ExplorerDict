# 翻译

从侧栏进入“翻译”，选择源语言与目标语言，输入或粘贴原文后点击“开始翻译”。支持自动识别源语言，以及简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语和阿拉伯语。源语言明确时可交换语言方向。

发现页可以带入摘要或简介；阅读页的“翻译”默认带入文章文本，有文字选区时只带入所选内容。原文和译文并排显示，均可滚动。

翻译沿用设置中的接口、模型、推理强度和加密密钥。只有点击“开始翻译”后才向模型发送原文；导航、选择语言和恢复页面不会发起请求。长文分段处理，显示进度。接口报告输出截断时，不把该段作为完成的译文保存。

原文、语言选项和译文保存在本机；切换页面不丢失任务，也不自动跳回翻译页。停止或失败时保留已完成的段落，并标明未完成。支持复制译文、导出 Markdown 或纯文本。译文单独保存，不修改原文，也不自动加入 RAG。

2026-10-24 已用配置中的 `deepseek-flash`、`high` 实际翻译公开短句“Robots can learn from demonstrations.”。该请求用于确认接口连通，不代表所有语言与长文的翻译质量均经过人工检查。
