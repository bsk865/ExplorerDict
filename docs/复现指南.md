# 源码运行指南

## 环境

Windows10/11 x64、PowerShell5.1+、CPython3.14 x64。当前开发环境为CPython3.14.5。准备过程访问Python包源与模型下载站点，建议预留至少2GB空间。

如果希望直接使用软件，可下载[Windows免安装包](https://github.com/bsk865/ExplorerDict/releases/tag/v1.0.20261025.3)，运行环境和本地向量模型随包提供。

## 10分钟快速体验

取得完整免安装包后，可以按下面的流程查看本地阅读与保存功能：

1. 解压整个目录，运行`探索词典-原生版.exe`。
2. 导入一篇文本或PDF，打开文章，查找一句话并添加标注与笔记。
3. 返回资料库，重新打开文章，确认阅读位置和笔记保留。
4. 如需体验模型功能，在设置保存自己的接口、模型、推理强度与密钥，再从文章旁提问或使用翻译工具。

免安装版已包含运行依赖和本地向量模型。源码运行按下节准备环境，实际安装与下载用时见[源码环境运行记录](源码环境运行记录-20261025.md)，其中列明缓存和网络条件。

## 准备与启动

```powershell
git clone https://github.com/bsk865/ExplorerDict.git
cd ExplorerDict
powershell -ExecutionPolicy Bypass -File scripts/setup-repro.ps1 -SkipTests
.build-env/Scripts/python.exe native_desktop.py
```

准备脚本建立`.build-env`、安装固定依赖、下载和校验模型、编译Windows UIA辅助库。安装与下载时间取决于网络和本机环境。

- `-SkipModel`跳过本地向量模型下载，使用关键词检索。
- `-ModelMirror https://hf-mirror.com`选择模型下载镜像。
- `-PythonCommand 'C:/路径/Python314/python.exe'`指定实际的Python3.14解释器；脚本核对版本和64位架构。
- 去掉`-SkipTests`运行全量检查，桌面用例需要相应运行环境。

固定程序版本对应源码提交`3049488`，可通过`git checkout 3049488`查看本版代码。主分支持续提供文档与后续开发更新。

## 依赖与本地模型

运行依赖固定在[requirements.txt](../requirements.txt)，打包工具在[tools/build-requirements.txt](../tools/build-requirements.txt)。PySide6提供主界面，Pillow、PyMuPDF和BeautifulSoup读取图文资料，onnxruntime与tokenizers运行本地向量模型，公式相关库支持阅读排版，pystray提供托盘。

本地模型为`Xenova/multilingual-e5-small`，revision为`761b726dd34fb83930e26aab4e9ac3899aa1fa78`。

| 文件 | SHA256 |
| --- | --- |
| `model_quantized.onnx` | `f80102d3f2a1229f387d3c81909990d8945513e347b0eab049f7de3c6f98c193` |
| `tokenizer.json` | `0b44a9d7b51c3c62626640cda0e2c2f70fdacdc25bbbd68038369d14ebdf4c39` |

模型保存在`models/multilingual-e5-small/`，准备脚本按摘要值确认文件。远端模型文件位于`onnx/`目录，本地直接放在模型目录根部，与应用读取路径一致。模型权重由下载步骤提供。

## 配置与开发资料

模型接口、模型名、推理强度和密钥在应用设置中保存。未配置模型服务时，可以导入、阅读、标注和整理资料。

[环境变量示例](../scripts/repro-env.example.ps1)提供独立资料位置的配置方式。应用从当前进程的环境变量读取配置。

| 变量 | 用途 |
| --- | --- |
| `EXPLORER_DICT_DATA_DIR` | 指定资料目录 |
| `EXPLORER_DICT_STORAGE_CONFIG` | 指定存储位置配置文件 |
| `QT_QPA_PLATFORM=offscreen` | 开发时离屏检查，正常打开窗口前移除 |

## 查看一条完整阅读流程

导入一篇公开或自编文本，打开“问本文”，添加标注和笔记。配置模型后提出问题，点击引用回到原句。随后在文章工具栏选择翻译，或进入导图整理结构。

关闭并重新打开后，资料、笔记、译文及偏好继续保存。外部划词通过Windows桌面辅助功能接口工作，主界面与浮窗共享资料目录。

## 定向检查与构建

仅确认源码环境能否运行时，可使用新的空目录完成一次独立启动检查：

```powershell
.build-env/Scripts/python.exe tools/check_repro_startup.py --output artifacts/my-source-startup --offscreen
```

工具使用独立资料目录，加载UIA辅助库，实际编码384维本地向量，导入并重新读取自编文章，再打开原生主界面并保存截图和JSON结果。不调用模型API；不启动外部划词组件。`--offscreen`用于离屏渲染，正常桌面查看可省略。输出目录必须为空或尚不存在。

按修改范围选择`tests/`中的模块。例如，发现页相关修改可运行：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.build-env/Scripts/python.exe -m unittest tests.test_discovery_updates tests.test_native_discovery -q
Remove-Item Env:QT_QPA_PLATFORM
```
