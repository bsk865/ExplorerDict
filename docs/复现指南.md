# 10 分钟复现指南（2.2 复现性声明与重现指南）

本文件对应参赛材料 **2.2 复现性声明与重现指南**。目标：在一台干净的 Windows 10/11 x64 机器上，从克隆仓库到跑通应用与测试，**约 10 分钟**（不含下载等待时波动）。

- 仓库：<https://github.com/bsk865/ExplorerDict>（Public，`main` 分支）
- 证据口径：原始 Prompt 链见 [参赛材料](参赛材料/2.1-材料核对清单.md)；验证记录见 [验收记录](../docs/验收记录)。
- 复现范围：应用可启动、原生取词界面可用、阅读工作区可用、全量单元测试通过。模型解释/问答需要使用者自备 OpenAI 兼容服务（可选，不影响本地功能复现）。

## 1. 前置条件

| 项 | 要求 | 验收环境 |
| --- | --- | --- |
| 操作系统 | Windows 10/11 64 位 | Windows 11 |
| Python | 3.12 及以上 | CPython 3.14.5 |
| 磁盘 | ≥ 1.5 GB（虚拟环境约 400 MB + 模型 136 MB + 依赖） | — |
| 网络 | pip 源 + Hugging Face（可换镜像） | 直连可用 |
| 其他 | PowerShell 5.1+；无需管理员权限；无需 Node.js | — |

## 2. 三分钟看清步骤

```powershell
git clone https://github.com/bsk865/ExplorerDict.git
cd ExplorerDict

# 一条命令：建虚拟环境、装依赖、下载并校验模型、跑冒烟测试
powershell -ExecutionPolicy Bypass -File scripts\setup-repro.ps1 -SkipTests

# 启动
.build-env\Scripts\python.exe bootstrap.py
```

`scripts\setup-repro.ps1` 是幂等的：已存在的虚拟环境、已校验通过的模型文件都会跳过；不改动应用代码与 `data/` 数据。参数：

| 参数 | 作用 |
| --- | --- |
| `-SkipModel` | 不下载模型（语义检索不可用，其余功能正常） |
| `-SkipTests` | 跳过全量测试（省约 90 秒） |
| `-ModelMirror https://hf-mirror.com` | 模型下载镜像 |
| `-PythonCommand py` | 指定解释器命令 |

## 4. 环境变量模板

应用**不读取 `.env` 文件**，以下变量按需在 PowerShell 会话中设置；全部可选，不设置即用默认值。

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `EXPLORER_DICT_DATA_DIR` | 项目内 `data/` | 数据目录（词库、阅读库、日志）；验收隔离时用它指到临时目录 |
| `EXPLORER_DICT_STORAGE_CONFIG` | 项目内 `storage-location.json` | 自定义「存储位置」配置文件的路径 |
| `EXPLORER_DICT_ALLOW_GUI_TESTS` | 未设置 | 设为 `1` 时允许 GUI 前置检查在无人值守环境创建窗口（仅测试用） |
| `EXPLORER_DICT_PDF_FONT` | 内置字体 | 导出 PDF 时替换字体文件路径 |

示例（隔离数据、不改动本机正式库）：

```powershell
$env:EXPLORER_DICT_DATA_DIR = "$PWD\.tmp\repro-data"
.build-env\Scripts\python.exe bootstrap.py
```

模型服务的 Base URL / 模型名 / API Key **不走环境变量**，在应用「设置」中填写：密钥经 Windows DPAPI 加密，仅存本机 `data/`，仓库与日志中均不出现明文。

## 5. 验证清单（复现通过的判定）

自动：

```powershell
.build-env\Scripts\python.exe -X utf8 -m unittest discover -s tests -t .
```

预期（发布提交口径）：**1545 项通过、26 项按环境跳过**；结果同步记录在 [2.1 材料核对清单](参赛材料/2.1-材料核对清单.md)。

手动（约 5 分钟）：

1. 启动后出现悬浮「探」按钮；在记事本/浏览器划词 → 面板展开（此刻不落库、不联网）；
2. 点「解释并记录」→ 词条入库（未配置模型时显示「已记录 · 待解释」）；
3. 主界面「阅读工作区」→ 导入一段文本 → 原文、标注、笔记页可用；
4. 资料库问答：未配置模型时应给出明确提示而不是假成功；
5. 全文导图、计划、探索统计、内容管理入口可打开；
6. 关闭窗口后进程退出，`data/` 下数据库写入正常。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| pip 安装慢/超时 | 换国内源：`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 模型下载失败 | 用 `-ModelMirror https://hf-mirror.com`；或手动下载后按上表校验 SHA-256 |
| 提示没有 Python | 安装 Python 3.12+ 并勾选 Add to PATH；或用 `-PythonCommand py` |
| 阅读窗口空白 | 先看 `data/logs/app.log`；本机已知问题记录在 [验收记录](验收记录)（QtWebEngine 渲染沙箱退出码 18），不影响原生取词与单元测试复现 |
| 端口被占用 | 阅读工作区使用本机回环随机端口；关闭残留进程后重试 |
| 首次启动向导 | 可直接「先随便看看」跳过，仅使用本地功能 |
| 想清空数据 | 删除 `data/`（仓库已忽略该目录）或用 `EXPLORER_DICT_DATA_DIR` 指向新目录 |

## 8. 复现性声明

- 仓库为 Public，`main` 分支按功能模块提交；源码、测试、验收记录、Prompt 链与本次指南同仓可查。
- 依赖与模型均固定版本/固定 revision 并给出 SHA-256，避免「今天能跑、明天不能跑」。
- 运行数据、日志、密钥、构建产物均不入库（见 `.gitignore`），复现从零开始，不依赖作者机器上的任何状态。
- 已知限制：模型解释与问答需要外部模型服务；离线向量检索仅覆盖中文文本资料；Windows 专用；不承诺游戏/反作弊兼容。
