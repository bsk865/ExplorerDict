# 原生版复现指南

更新：2026-10-25。当前入口为 `native_desktop.py`。以下提供完整运行步骤。下载耗时受网络影响，本版尚未在干净机器上完成计时。

## 环境

Windows 10/11 x64、PowerShell 5.1+、Python（开发环境为CPython 3.14.5，推荐3.14）。需要访问Python包源与模型下载站点。建议预留至少2GB。无需Node.js或浏览器服务；UIA辅助库用Windows自带.NET Framework编译器构建。

## 一条准备命令

```powershell
git clone https://github.com/bsk865/ExplorerDict.git
cd ExplorerDict
powershell -ExecutionPolicy Bypass -File scripts/setup-repro.ps1 -SkipTests
.build-env/Scripts/python.exe native_desktop.py
```

脚本建立 `.build-env`、安装固定依赖、下载和校验模型、编译UIA辅助库。`-SkipModel` 可跳过模型下载，此时保留关键词检索；`-ModelMirror https://hf-mirror.com` 可指定下载镜像；`-PythonCommand py` 可指定解释器。去掉 `-SkipTests` 会运行全量测试，部分桌面测试需要额外环境，耗时与结果不能套用历史统计。

## 环境变量模板

可复制 [scripts/repro-env.example.ps1](../scripts/repro-env.example.ps1) 中的命令；应用不自动读取 `.env`。

| 变量 | 用途 |
| --- | --- |
| EXPLORER_DICT_DATA_DIR | 覆盖数据目录，复现时可指向隔离目录 |
| EXPLORER_DICT_STORAGE_CONFIG | 覆盖存储位置配置文件路径 |
| QT_QPA_PLATFORM=offscreen | 仅供离屏测试；普通运行不要设置 |

接口地址、模型、推理强度和密钥在应用设置中保存。密钥使用Windows DPAPI，不写入源码、模板或公开日志。未配置密钥也可导入、阅读、标注和整理资料。

## 复现动作

1. 运行原生窗口，导入自编文本，确认文章出现在资料库。
2. 打开文章，点击“问本文”，确认原文和追问侧栏可同时使用。
3. 写一条笔记、添加一个计划，关闭再打开，确认记录仍在。
4. 选择天气城市后重启：先恢复城市，再更新天气；联网失败也不要求重选。
5. 配置模型后自行进行一次问答并点击引用；此步会向指定服务发送问题和相关材料。
6. 跨应用划词与主题同步在真实桌面另行试用，不能用离屏检查代替。

## 常见问题

- 看不到窗口：确认没有给普通启动设置 `QT_QPA_PLATFORM=offscreen`。
- 没有向量模型：先用关键词检索，稍后重新执行准备脚本下载模型。
- 悬浮组件没有启动：确认UIA辅助库已编译；源码入口可直接启动bootstrap子进程，打包版必须携带悬浮组件及运行库。
- 看不到原来的资料：确认两次启动使用同一数据目录；不要清空或覆盖原库。
- 安装/升级：见[原生版构建与安装](原生版构建与安装.md)，普通安装和跨版本升级仍需验收。
