# 使用指南

## 下载与打开

在 [Releases](https://github.com/bsk865/ExplorerDict/releases/tag/v1.0.20261025.3) 下载 Windows x64 免安装包，解压全部文件，双击“探索词典-原生版.exe”。运行环境随包提供。移动软件时请保留完整目录。

第一次打开后可先导入一篇资料，体验阅读和笔记。需要模型功能时，打开“设置”，填写服务商接口地址、模型、推理强度和 API 密钥，再保存。图片理解和图文导图需要模型支持图片输入。

## 发现值得阅读的内容

启动默认进入“发现”。可以浏览新闻和论文，也可以在“兴趣与来源”填写兴趣方向、查找网站订阅、暂停或添加来源。

点击“更新内容”获取来源的最新内容。结果分别统计新增与修改；来源本身没有变化时显示“暂无新增或修改”。有变化时点击“查看本次更新”集中浏览。“最新发布”优先展示各来源较新的文章，选择单个来源可按发布时间查看；排序选择下次打开自动恢复。

粘贴公众号、浏览器文章或PDF公开链接，点击“收集链接”即可保留入口。在详情中选择“获取全文并加入资料库”，取得正文后打开阅读。新闻封面来自原始网页或订阅，来源的具体更新情况在“兴趣与来源”查看。[发现与订阅](发现页.md)

## 导入自己的资料

从资料库选择文件，支持PDF、DOCX和文本，也可以直接粘贴内容。多文件导入显示逐项进度，停止后已完成的资料保留。

网页、直接PDF链接、arXiv及公开声明PDF的论文详情页共用全文读取流程。下载的论文PDF原件与正文一并保存，可在阅读页“资料信息”另存。摘要作为独立内容类型显示；已保存的摘要可以继续获取全文。

## 在原文中阅读与记录

打开文章后，使用Ctrl+F查找文字；Enter或F3前往下一处，Shift配合快捷键返回上一处，Esc收起查找。选中文字添加标注或探索词条，在旁边写下自己的笔记。

图片可以放大、拖动和框选；点击“适应窗口”恢复全图。公式可以在文章内展开查看。文章操作中的“导出笔记”可保存原文、标注、问答引用、笔记与本文译文。[阅读与笔记](阅读笔记.md)

## 边读边问

点击“问本文”打开文章旁的对话栏，输入问题并发送。默认围绕当前文章查找依据，也可扩大到资料库。点击回答的引用可回到原文并高亮对应文字。

“资料库问答”默认查阅已加入的本地资料，后续新增文章自动纳入。范围选择用于缩小查阅范围，可以按文章或主题组织问题。图片问题可先框选需要理解的区域，再发起理解。[问答与引用示例](screenshots/multi-public-rag-20261024/README.md)

## 对照翻译

在文章工具栏点击“翻译”，选择源语言与目标语言，开始后对照查看原文和译文。可停止、继续、复制或保存。语言、草稿、译文与任务分别属于当前文章，切换文章后各自恢复。

从浮窗或发现摘要进入的翻译按相应来源保存。[翻译说明](翻译.md)

## 整理导图与学习计划

进入本文“导图”，文字资料选择正文模式，扫描页选择图文模式。生成后查看节点和关系的原文依据；可修改文字、新增节点、调整层级、编辑关系、拖动布局或撤销操作。导出包含完整导图。[导图操作](导图.md)

在计划中描述学习目标和可用时间，确认安排后保存。应用结合已有日程分配时间，显示待办和完成记录；偏好面板可调整日期、每日时段与学习用时。

## 浮窗、主题与资料保存

浮窗承接外部应用中的划词，主界面负责完整阅读与整理。两者共用资料目录、模型配置和主题。选择配色、明暗模式或天气城市后，下次打开会恢复。

资料默认保存在程序目录的 `data` 中。设置里可以查看当前保存位置并选择新的空文件夹，应用完全退出后完成迁移。备份时先退出程序，再复制整个资料目录。API密钥使用Windows DPAPI保存，换电脑后重新填写。[资料与模型请求](信息存储与上下文说明.md)

## 常见问题

- **更新后列表相同**：查看新增和修改数量；若均为0，说明来源返回的是已有内容，可尝试最新排序或其他来源。
- **网页全文无法获取**：可打开原站阅读，或导入自己取得的原文件。
- **模型功能不可用**：在设置中确认接口、模型和密钥，并查看页面中的具体错误。
- **找不到原来的资料**：在设置中确认资料目录，与之前使用的路径保持一致。
- **开发环境没有显示窗口**：普通运行前移除 `QT_QPA_PLATFORM=offscreen`，见[源码运行](复现指南.md)。
