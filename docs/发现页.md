# 发现：新闻、论文与文章收集

启动原生版后进入“发现”。页面提供推荐、新闻、论文、收集、收藏五个入口；原来的今日计划仍在侧栏。

## 阅读流程

1. 点击“更新内容”获取订阅；有缓存时先展示缓存。默认启动更新间隔至少6小时，可在“兴趣与来源”关闭。
2. 在“兴趣与来源”填写关注方向，或让本机阅读标题、探索对象、笔记与提问帮助排序。支持关闭个性化推荐、屏蔽关键词和恢复被忽略的内容。
3. 点击卡片“查看内容”阅读来源简介或论文摘要，打开原站，或主动加入资料库。资料库中的内容才进入 RAG 范围。
4. 在“粘贴公众号或浏览器文章链接”输入公开文章地址，点击“收集链接”，随后在“收集”中查看。

新闻封面优先采用 RSS/Atom 中的图片，其次尝试网页 Open Graph/Twitter 封面；加载失败显示文字卡片。不生成图片，不使用图片代理，不移除水印。封面保存在本机缓存中。图片与来源文章的权利归原始来源所有。

论文保留作者、来源和发布日期；arXiv 标注为预印本。加入资料库时保存来源摘要，长度受限时标明摘要节选，均不作为论文全文。需要全文时，可从原站下载文件并导入。

## 来源接口

- 默认公开订阅：IT之家、BBC 科技、ScienceDaily、arXiv 人工智能与机器人。
- 可添加最多10个 RSS/Atom 来源，支持暂停和移除。暂停或移除后不再推荐该源；已经收藏的内容仍可从收藏入口阅读。
- 公众号采用公开文章链接与 `#js_content` 正文区域适配。无法访问、需要登录或验证码时，在原站阅读；不提供公众号账号登录或全量订阅抓取。
- 浏览器入口目前为复制文章链接到应用；浏览器扩展不属于本版交付。

`app/discovery.py` 提供 `parse_feed`、`metadata`、`Discovery.refresh`、`add_link`、`import_item` 接口。新增来源可复用统一内容结构，包括原文地址、标题、来源、发布时间、摘要类型、原站封面及本地图片缓存。

## 数据与界面

兴趣分析和排序在本机完成，没有付费模型调用，不上传用户资料或兴趣画像。远端仅接收订阅、网页和图片的普通读取请求。定期缓存最多400条非收藏订阅内容；收藏与主动收集的链接保留。来源更新失败不清空既有内容。

兴趣设置、内容预览、错误与进度均在页面内显示，沿用主界面主题；不打开系统通知或新增原生对话框。离开页面后，后台更新完成不会主动跳回发现页。

公开内容能否提取全文取决于来源结构与访问条件。正文缺失时不会把网页简介冒充全文加入资料库。
