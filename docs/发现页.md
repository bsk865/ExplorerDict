# 发现：新闻、论文与文章收集

启动原生版后进入“发现”。页面提供推荐、新闻、论文、收集、收藏五个入口；原来的今日计划仍在侧栏。

## 阅读流程

1. 点击“更新内容”获取订阅；有缓存时先展示缓存。默认启动更新间隔至少6小时，可在“兴趣与来源”关闭。
2. 在“兴趣与来源”填写关注方向，或让本机阅读标题、探索对象、笔记与提问帮助排序。支持关闭个性化推荐、屏蔽关键词和恢复被忽略的内容。
3. 点击卡片“查看内容”预览来源简介或论文摘要，再用“获取全文并加入资料库”导入正文。资料库中的内容才进入 RAG 范围；预览不等于已取得全文。
4. 在“粘贴公众号或浏览器文章链接”输入公开文章地址，点击“收集链接”，随后在“收集”中查看。

新闻封面优先采用 RSS/Atom 中的图片，其次尝试网页 Open Graph/Twitter 封面；加载失败显示文字卡片。不生成图片，不使用图片代理，不移除水印。封面保存在本机缓存中。图片与来源文章的权利归原始来源所有。

论文保留作者、来源和发布日期；arXiv 标注为预印本。arXiv 全文入口下载原始 PDF，提取全部页面并保留各页图像；原始 PDF 保存在本地资料库，可从阅读页“资料信息”另存。下载或解析失败时显示原因，不自动改存摘要。

“仅保存摘要”是单独的选项，明确标为非全文。此前已保存的摘要可以继续获取全文，旧摘要及其笔记保留。其他论文来源需提供可访问 PDF 或具有完整章节的正文；只有摘要、付费或登录页面时可手动导入合法取得的原文件。

“翻译摘要/简介”打开当前条目的内嵌翻译工具；导入全文后，阅读工具栏“翻译”在文章内带入正文，选中内容时带入所选文字。各篇文章与各条发现内容的译文独立保存。[翻译使用说明](翻译.md)

打开原站使用系统默认浏览器。当确认 Edge 与词典进程权限不同时，应用显示页内提示并保留“复制链接”，不请求提升权限或重启浏览器。

## 来源接口

- 默认公开订阅：IT之家、BBC 科技、ScienceDaily、arXiv 人工智能与机器人、The Guardian 科技、NPR 科技、Solidot、PLOS ONE、The Conversation 科技，共10个栏目、9个平台。
- “更多平台”提供少数派、Nature 科研动态、eLife 研究动态及 Hacker News 社区，可直接订阅，最多30个来源。在“兴趣与来源”粘贴网站或 RSS/Atom 地址，点击“查找订阅”，从实际验证可用的入口中选择并订阅。网站没有声明订阅时，会查找已收录的同平台官方入口；没有可用入口时可继续收集文章链接。
- 推荐按平台交错展示；同平台的多个栏目共用一个推荐队列，约每五条尝试穿插一个非当前兴趣方向的候选。没有其他平台或方向时如实展示已有内容，不生成替代新闻。来源筛选可查看单一订阅。
- 来源管理显示各源最近成功更新时间、条数和错误；合法订阅本期为空时显示“本期暂无新文章，已保留上次内容”。请求失败或内容无法解析时显示原因。暂停或移除后不再推荐该源；已经收藏的内容仍可从收藏入口阅读。同一链接由多个订阅提供时保留各自来源，移除其中一个不影响其他仍有效的订阅。
- 公众号采用公开文章链接与 `#js_content` 正文区域适配。无法访问、需要登录或验证码时，在原站阅读；不提供公众号账号登录或全量订阅抓取。
- 浏览器入口目前为复制文章链接到应用；浏览器扩展不属于本版交付。

`app/discovery.py` 提供 `find_feeds`、`parse_feed`、`metadata`、`Discovery.refresh`、`add_link`、`import_item` 接口。新增来源可复用统一内容结构，包括原文地址、标题、来源、发布时间、摘要类型、原站封面及本地图片缓存。

## 数据与界面

兴趣分析和排序在本机完成，没有付费模型调用，不上传用户资料或兴趣画像。远端仅接收订阅、网页和图片的普通读取请求。定期缓存最多400条非收藏订阅内容；收藏与主动收集的链接保留。来源更新失败不清空既有内容。

兴趣设置、内容预览、错误与进度均在页面内显示，沿用主界面主题；不打开系统通知或新增原生对话框。离开页面后，后台更新完成不会主动跳回发现页。

公开内容能否提取全文取决于来源结构与访问条件。正文缺失时不会把网页简介冒充全文加入资料库。

2026-10-24 最近一次隔离联网读取取得220条内容、8个平台、6张原站封面，未报告请求或解析错误。两个 arXiv 栏目当次返回合法空列表，标注周末不更新；页面显示本期暂无新文章，有缓存时保留。网站地址查找已实际识别少数派的官方订阅入口。没有以历史条目冒充本次新增文章。
