# 资料与模型请求

## 本地保存

文章、词条、对话、译文、导图、笔记与计划保存在用户选择的资料目录中。免安装版默认使用程序目录下的 `data`，设置可查看当前位置并安排迁移。

| 内容 | 保存方式 |
| --- | --- |
| 文章、版本、图片与引用 | 阅读工作区数据库与资料文件 |
| 词条、划词上下文和共享设置 | 词条数据库与配置 |
| 对话、译文、笔记与计划 | 按文章、来源或会话保存 |
| 本地语义索引 | 资料片段与本地向量 |
| 发现内容和封面 | 独立订阅缓存 |
| 导出文件 | 用户选择的保存位置 |

主界面与浮窗使用共同的资料目录、模型配置和主题。密钥使用Windows DPAPI加密保存；文章等资料属于普通本地文件和数据库。换电脑后在设置中重新填写密钥。

## 模型使用哪些材料

资料问答根据当前问题和选择范围，先在本机检索相关原文，再组织问题、相关片段与会话发送给设置中的模型。图片问题使用相应图片或框选区域。翻译使用所选文章内容；导图使用正文或图文材料；规划使用学习目标、偏好和相关日程。

本地向量检索由随包提供的模型运行。联网模型功能使用用户配置的服务，服务端的数据处理方式以该服务政策为准。可以在设置中调整模型、推理强度与问答上下文预算。

## 备份与迁移

备份前退出主界面和浮窗，再复制整个资料目录。恢复时在设置中选择相应存储位置。迁移使用新的空目录，应用完全退出后生效，原目录保留。

下载的公开论文PDF可在阅读页“资料信息”另存。其他本地原文件建议单独保留；导入后的正文与图片继续保存在资料库中。需要分享学习成果时，可以导出阅读笔记或完整导图。
