# 阅读版 2：原文工作台修正

日期：2026-10-14。本次用户反馈优先于先前原型方案：文章本身就是工作台；不允许将公式源码、重复备用文本或局部片段冒充可读全文。

## 界面与使用路径

- 原网页／文档阅读：使用原有桌面取词助手。进入阅读版不要求同时打开另一套工作台。
- 应用内阅读：提取网页或导入资料后，默认显示宽幅原文。选词、点图后展开唯一的助手侧栏；可随时收起。
- 删除常驻的三栏工作布局。对象通过助手中的当前内容选择器切换，理解与笔记为两个页签。图片与局部框选共用该助手。
- 导图独立切换；树形曲线表达层级，语义关系逐条查看，不叠加交叉连线。
- 历史错误提取含公式源码时，显示重新提取入口，不继续作为正常原文展示。

## 具体修正

原论文网页只保存了 1,223 字片段，且 MathML 的备用 LaTeX 注释混入正文。修正语义 article/main 提取与原文顺序，新增安全富文本快照：保留段落、标题、表格、MathML 与可下载的同源插图，移除注释、脚本和主动内容。无明确文章区域时返回失败，不把密度片段称为全文。真实代码块显示原网页查看提示。

已从指定公开 arXiv 网页恢复阅读快照：511 块，138,313 个文本字符（含公式文本及图注），843 个 MathML 元素，5 张图片，无下载缺失。它是重新排版的阅读快照，不是原网页像素复刻；部分图注公式当前保存为纯文本。

生产旧快照及其对象、对话逐条保留。新旧版本通过 previous_id / superseded_by 连接；文章操作中可查看旧收藏版本。未推测迁移旧引用位置。修复前 SQLite 在线备份位于 artifacts/reader-v2-backup-20261014-220021/。原 explorer_dict.sqlite3 哈希未改变。

## 仍需明确的范围

此版问答单次最多使用 26,000 字符的正文材料；选词／选图时使用附近段落。长文页面明确提醒先选择具体位置。全文导图仍限制 30,000 字符，本论文可完整阅读但尚不能生成完整全文导图；不会截断后冒充完整导图。已有短文导图功能保留。

原有浮动助手仍是独立桌面窗口，不会因任意切换焦点而自动消失。进入应用内阅读时可使用它自身的收起按钮，避免遮住原文。此轮没有改变用户既定的浮窗保持规则。
