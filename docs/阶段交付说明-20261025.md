# 探索词典 · 阶段交付

版本：1.0.20261025.3，2026-10-25，Windows 10/11 x64。

探索词典将发现、原文阅读、跨应用划词、资料问答与学习整理连接在同一个本地空间。本版提供完整的桌面阅读与学习流程，后续版本继续完善复杂资料和细节交互。

[下载本版](https://github.com/bsk865/ExplorerDict/releases/tag/v1.0.20261025.3)

## 使用入口

本机使用桌面“探索词典 · 发现版”。独立交付优先使用免安装包：解压整个目录，双击“探索词典-原生版.exe”，不要只复制单个EXE。首次使用在设置中填写自己的模型接口和密钥。安装器作为同版本附带文件提供，免安装版无需写入系统注册。

## 主要功能

- 发现：不同平台新闻、论文、兴趣排序、订阅管理、原站封面、链接收集和收藏。
- 更新：区分新增、修改与重复记录，提供最新发布和本次更新筛选，记住排序选择。
- 阅读：网页与文件导入、公开论文全文及PDF原件、查找、图片查看、标注和随文笔记。
- 翻译：文章工具栏选择语言、对照阅读，译文按所属文章保存。
- 问答：默认查阅本地资料库，支持文章旁追问、混合检索和可定位的原文引用。
- 整理：导图生成和编辑、资料分类、学习规划、统计及内容管理。
- 联动：主界面和浮窗共用资料、模型设置与主题；城市和用户偏好持久保存。

## 本版收尾

发现页不再把重复读取数当成新增内容；没有变化时明确显示结果。精简发现、来源管理、问答、翻译、导图及设置中的说明，保留必要状态与操作名称。主要交互使用应用主题控件。

## 后续完善

小窗口模式维持当前状态。更复杂的资料、长时间跨应用使用、早期版本迁移和正式签名安排在后续版本。本次免安装版为主要交付形式；普通安装的系统注册曾受权限限制，尚未确认解决。

交付包不包含用户资料、API密钥或本机存储路径；联网来源和模型服务需要可用网络及用户自己的授权配置。源码与具体构建记录见[开发状态](开发状态.md)。
