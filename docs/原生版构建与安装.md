# 构建与分发

## 生成Windows程序

在已准备好的开发环境中运行：

```powershell
.build-env/Scripts/python.exe -m pip install -r tools/build-requirements.txt
./tools/build_native.ps1
```

默认输出目录为`artifacts/native-build/dist/探索词典-原生版/`。保留整个目录，双击“探索词典-原生版.exe”启动。输出路径可以通过`-OutputDirectory`指定。

主包默认同步重建UIA辅助库与浮窗组件，再打包PySide6主界面。辅助库在隔离目录编译，组件记录源码与EXE的摘要值；主包复制前确认组件对应当前源码。`-ReuseCompanion`适用于组件与源码已经一致的情况。

包内容检查覆盖两个入口、运行库、主题图片、本地模型和个人资料排除规则。程序分发前使用干净构建目录，存储配置由首次运行生成。

## 生成安装器

```powershell
./tools/build_native_installer.ps1 -Version 1.0.20261025.3
```

安装器使用Inno Setup，默认编译器路径为`artifacts/tooling/inno/ISCC.exe`，可以通过`-Compiler`指定。`-PackageDirectory`选择程序目录，`-OutputDirectory`选择输出目录。安装器编译前检查包内容。

当前下载版以[免安装ZIP](https://github.com/bsk865/ExplorerDict/releases/tag/v1.0.20261025.3)分发。安装器的系统注册权限与发布者签名在后续版本继续完善。

## 存储与升级

免安装版默认使用程序目录下的`data`。已有存储位置配置时，程序继续读取所选位置。备份前先退出主界面和浮窗，再保存整个资料目录；升级时完整保留资料与配置。

主界面和浮窗共同使用资料位置与主题。同一目录启动相同构建时呼出已有窗口；启动不同构建时，所选版本等待旧实例保存退出后接管。

安装器的默认目录为`%LOCALAPPDATA%\Programs\ExplorerDictNative`，卸载保留用户资料和存储位置配置。

## 构建检查工具

| 工具 | 用途 |
| --- | --- |
| `tools/audit_native_package.py` | 检查运行资源、组件与资料排除规则 |
| `tools/companion_manifest.py` | 核对浮窗组件与当前源码 |
| `tools/check_native_desktop.py` | 在独立资料中运行打包程序的主要页面流程 |
| `tools/check_native_installer.py --isolated` | 安装、覆盖和卸载保留的文件流程 |
| `tools/check_native_relocation.py` | 独立资料目录的迁移流程 |

系统注册、真实跨应用划词和文件流程按各自环境检查。具体版本记录见[版本进展](开发状态.md)，历史构建与交付结果见[开发记录](history/开发记录-20261025.md)。

## 生成项目技术文档

技术正文在[项目资料/技术文档.md](项目资料/技术文档.md)。安装[文档构建依赖](../tools/document-requirements.txt)后生成PDF：

```powershell
python -m pip install -r tools/document-requirements.txt
python tools/build_project_pdf.py
```

脚本从Markdown正文生成同目录PDF，并更新系统架构图。
