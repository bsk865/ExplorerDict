# 当前开发状态

更新：2026-10-24。维护对象为 `native_desktop.py` 与 `app/native/`，并与悬浮取词组件协同。原生迁移处于试用与补齐阶段，不使用没有逐项依据的完成百分比。

## 当前已经实现

- 启动进入“发现”：新闻、论文、链接收集与收藏；本机兴趣排序、来源管理、关键词屏蔽、忽略与恢复。
- 支持 RSS/Atom、公众号公开文章和浏览器文章链接；封面取自订阅源或原网页，失败回退文字卡片。默认接入 IT之家、BBC 科技、ScienceDaily 与 arXiv AI/机器人。
- 发现缓存与资料库分离，只有主动加入后参与 RAG；论文摘要和摘要节选明确标识，网页正文无法读取时保留原站入口。
- 发现页预览与设置均为页内交互；后台更新返回不会触发跳页或新弹窗。来源失败保留缓存，启动更新间隔至少6小时。

- 今日、主题资料库、阅读、标注、笔记、内容管理、计划、统计、导图、资料库问答、RAG 索引、六套主题与设置。
- 主界面和悬浮窗共享数据目录、模型配置、密钥存储及主题；组件采用独立进程，通过本地事件协调启动和退出。
- 设置提供可编辑模型选择、推理强度；预算区为滑轨、保存预设、恢复默认值。
- 资料库问答默认全库，新增文章自动纳入；会话保留草稿与历史。抓取上下文作为片段检索，引用保留来源类型。
- 阅读页“问本文”开启侧栏，可边读边问；仍可手动缩小资料库范围。
- 下拉菜单主题统一；关闭的选项框及预算滑轨向父页面转交滚轮。
- 天气城市持久保存；启动先读取本地城市或缓存，再联网更新。换城市期间已有请求结束后会刷新新城市。
- 阅读页支持文内查找：Ctrl+F、匹配数量、上一处/下一处、Enter/Shift+Enter 与 F3/Shift+F3 循环跳转，Esc 收起；保留既有标注。
- 本地文件支持多选导入、逐项进度与失败反馈；可停止后续导入，已经完成的资料保留。
- 删除笔记或资料后，资料库问答继续保留原来的全库/指定范围设置。
- 阅读问答侧栏随窄窗调整下拉框宽度，操作按钮按可用宽度换行；隐藏按钮不再占据排布空间。
