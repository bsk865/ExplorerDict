- 支持 RSS/Atom、公众号公开文章和浏览器文章链接；封面取自订阅源或原网页，失败回退文字卡片。默认10个栏目、9个平台，涵盖中文社区、国际新闻、科学传播、学者观点与开放论文。

- 发现缓存与资料库分离，只有主动加入后参与 RAG；论文摘要和摘要节选明确标识，网页正文无法读取时保留原站入口。

- 阅读工具栏提供翻译功能：源语言与目标语言选择、自动识别源语言、原文译文对照、分段进度、停止、复制与保存；每篇文章独立保存语言、原文草稿、译文和任务，切换文章不串内容，不改写原文。发现预览与外部来源另行隔离。
- 原站链接沿用默认浏览器；确认 Edge 权限冲突时显示应用内提示与复制链接入口，不请求管理员权限或重启浏览器。
- 发现页预览与设置均为页内交互；后台更新返回不会触发跳页或新弹窗。来源失败保留缓存，启动更新间隔至少6小时。

- 今日、主题资料库、阅读、标注、笔记、内容管理、计划、统计、导图、资料库问答、RAG 索引、六套主题与设置。
