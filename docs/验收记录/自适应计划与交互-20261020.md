# 自适应计划与交互整理

## 已实现

- 计划顾问默认只显示自然语言输入，日期和时段限制收在可选偏好中，不再要求逐项填写。
- 追问以对话呈现，后续补充携带原目标；草稿及对话在本机恢复。旧版自动填入的晚上时段不自动作为新版限制。
- 模型根据本地日期理解相对时间、建议预计用时；仅关键缺口追问。候选资料仅提供标题及字数，自动关联已知文章 ID，仍校验时间、冲突和用户明确限制。
- 统一计划弹窗的输入框高度、栅格、按钮间距与滚动边界；整理任务行、主题条目、统计和天气区域布局。
- 天气区加入晴、云、雨、雪、雾和雷雨矢量图标，跟随天气代码显示。没有可用的 image2.5 工具，因此本轮不是 image2.5 生成素材。
- 思考状态改为头像、三个轻微跳动的点和一句状态，耗时与用量折叠；尊重减少动画设置。
- 请求发出前立即反馈并锁定重复提交，失败后释放状态；完成任务原位更新，不重绘整页；页面独立请求同时加载，并过滤过期导航结果。

## 验证

- 全量 unittest：1500 项，26 项跳过，其余通过，约 59 秒。测试中的预期故障日志不作为实际运行故障。
- 独立真实模型试验：当前配置 `deepseek-flash`，只发送虚构需求“明天上午开会，下午读公开文章并整理心得”。约 5.1 秒生成两项明天下午的计划，无额外问题，数据存于隔离临时目录。单次样例不代表所有需求的准确率或响应耗时。
- 浏览器测试采用 Edge/Playwright：本会话未提供 Browser 技能。验证可选限制、保留原目标的两轮对话、任务完成原位更新、天气图标、1280x900 和 390x844 布局与深色模式。

- 构建包以隔离数据运行实际 EXE，通过本地测试模型服务验证计划 API 与前端完整交互，并通过 Qt 渲染、最大化、还原、最小化和关闭检查。证据：`%TEMP%/adaptive-study-qdy7_ih8/`。
