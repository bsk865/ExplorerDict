# 内容管理与笔记计划整理

## 用户需求

用户要求添加的内容都有管理和删除入口，并指出计划与笔记管理混乱、布局不合理。先整理这两项，再核查资料库管理入口。

## 交付内容

- 计划列表按日期归组，支持搜索、未完成/已完成筛选，每项直接提供编辑与删除。
- 新增独立笔记管理页，支持新建、全文编辑、按文章筛选、搜索、查看原文与删除；旧对象/文章笔记保留独立编辑和清除入口。
- 新增内容管理入口，覆盖文章、主题、计划、笔记、探索对象、问答交接、规划记录、导图草稿、阅读记录、天气城市和未提交草稿。
- 主题资料库文章列表直接提供删除按钮；资料库问答的管理资料入口仍回到同一资料库。
- 输入框与下拉控件统一高度、基线与宽度；桌面和窄窗口分别检查。

## 删除边界

| 内容 | 删除影响 |
| --- | --- |
| 文章 | 连同历史版本、探索对象、笔记、导图、问答删除；计划保留并移除文章关联 |
| 主题 | 只删除分类与分类关联，文章保留 |
| 笔记 | 删除笔记本身，历史回答中的引用快照保留 |
| 计划 | 删除该任务，文章与笔记保留 |
| 规划记录 | 删除历史记录，不自动撤销已生成任务 |
| 探索对象 | 删除对象、对象笔记与问答；同步词条一并删除，原文原图保留 |
| 问答 | 清空对应消息、输入草稿和交接记录，独立笔记保留 |
| 导图 | 删除该文章版本的导图和生成草稿，原文保留 |
| 阅读记录 | 清除阅读访问与完成标记，下次阅读可重新生成 |
| 天气城市 | 删除城市与天气缓存 |
| 未提交草稿 | 丢弃草稿，不改动已保存内容 |

删除需要明确确认；全程仅在隔离测试库执行添加和删除验收，没有清理用户生产资料。
