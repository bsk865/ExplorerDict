## API 与取词修复

- API 每次请求刷新实际代理路由，独立 opener 避免沿用全局代理快照；错误按配置、代理、DNS、TLS、网络、超时、鉴权、付费、限流、模型、端点及响应结构分类。
- 临时故障默认最多 3 次重试，基础等待 1/2/4 秒并加抖动，单次上限 8 秒；遵守 Retry-After 和总预算。永久错误不盲重试。解释面板显示重试进度，支持停止，保持词条和 token 归属。
- 取词启动以真实握手判定就绪；服务准备提前调度；合并积压手势；读取成功后不再无用遍历祖先；原生接口预编译并同步打包。
- 增加初始化、队列、读取、显示分段计时。初始化超过当前取词预算时仍可能漏掉该次手势，尚未实现自动补读。
