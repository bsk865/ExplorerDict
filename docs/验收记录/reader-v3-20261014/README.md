# 阅读版 3 功能闭环验收

- 默认入口：探索词典-阅读版3.exe；依赖目录 _reading_runtime_v3；会话与旧版本分开。
- 构建部署 108 个文件逐项 SHA256 一致。未覆盖、终止原取词程序与旧阅读程序，未改写生产文章数据库。
- Python 回归 90 项通过。覆盖全文提取、MathML 清理、资料持久化，以及新增笔记/草稿独立更新、旧版本收藏可见、模型返回不覆盖在途笔记。
- 安装包通过独立 Edge 的 15 项主流程与 6 项并发/错误恢复检查。浏览器插件不可用，使用现有 Playwright，未操作用户前台窗口。
- 主流程：文章笔记→切换保存→笔记列表→返回→导出；提问→设置入口→模拟失败→重试→回答→原文定位；窄屏；空导图与长文目录。
- 并发流程：选词使用简洁用户问题；回答中写笔记，结果返回后笔记保留并持久化；停止后问题保留；图片能力未确认时引导检测。
- 模型响应与网络失败使用明确的合成测试响应，无真实模型请求、无生产文章外发。本轮不新增关于真实模型质量的结论。
- 人工查看 conversation.png、notes.png、mobile.png。脚本与结果同目录；脚本针对 .tmp/reading-workflows 隔离数据运行。
- 长文全文导图限制仍为 30,000 字符；文章目录是导航功能，不冒称模型生成导图。问答单次仍限制 26,000 字符附近正文材料。

新功能：文章笔记、词图笔记自动保存与本机未提交恢复、笔记搜索与旧版入口、导出文章笔记、聊天失败/取消/重试、引用可读标签、未配置模型与图片检测引导、长文目录、空导图单一操作入口。

界面移除内部提示词、原始引用编号、版本哈希与生成/复核流程说明；用户直接输入的内容不作删改。旧版自动生成的固定解释指令仅在显示时转为普通操作名称，存档保持原样。
