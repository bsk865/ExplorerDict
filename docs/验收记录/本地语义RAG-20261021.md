# 本地语义 RAG 验收

## 实现

- 模型：Xenova/multilingual-e5-small，固定提交761b726dd34fb83930e26aab4e9ac3899aa1fa78；原始模型intfloat/multilingual-e5-small，MIT许可证随运行包分发。
- ONNX int8、CPU推理、384维、带query/passage前缀的masked mean pooling与L2归一化。模型和tokenizer均通过固定SHA256校验，下载脚本为tools/fetch_rag_model.py。
- SQLite持久化rag_documents/rag_vectors，语义精确余弦检索与BM25式关键词检索经RRF融合。向量不依赖在线API或外部向量服务。
- 指纹覆盖原文版本和笔记内容。推理不占用资料写锁，发布前重新验证版本、删除状态与重建代次。检索再核对当前指纹及授权范围；笔记默认不参与问答。
- 知识索引页面提供状态、片段预览、原文定位与重建；原始内容通过现有资料/笔记管理入口删除。问答显示实际混合或关键词检索方式。

## 质量证据

在用户现有两份可见文字资料的隔离副本上测试，未修改用户原文、未调用回答API。

- 生成1445个片段；修正后的源代码实测索引约11.48秒，混合检索约44至48毫秒。计时只适用于本机与本次资料规模，不包括在线回答耗时。
- 首轮预先固定的问题包含4个英文跨语言问题和2个中文改述。初始阈值0.78时，4个跨语言问题都未召回预期片段，无关蛋糕问题还返回4个候选。保留失败结果：artifacts/real-rag-initial-calibration.json。
- 根据首轮问题进行嵌入空白规范化并将候选阈值调整为0.82，之后冻结另一组6个中文改述问题。预期依据全部进入前4；5个进入前3。前三命中数量与词项检索相同，混合检索改善了急停按钮问题的第一名以及头盔问题的排序，并非所有问题都提升。
- 该轮无关蛋糕问题的语义候选为0；这只是一个拒绝样例，不代表可以全面识别无关问题。结果：artifacts/real-rag-held-out.json；复测脚本：tools/check_real_rag.py --held-out。
- 当前无独立重排模型、OCR和图文统一向量检索；跨语言检索质量尚未达标，回答忠实度尚未做独立模型评测。
