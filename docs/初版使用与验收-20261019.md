# 探索词典初版 1：使用与验收

定位：学术文献多模态 RAG 研读助手。原文、原图是依据；解释、笔记和导图围绕阅读展开。

## 使用入口

程序：项目根目录 `探索词典-初版1.exe`，配套 `_reading_runtime_v7`。原生悬浮取词仍使用同目录 `探索词典.exe`、`_runtime` 与 `app/`，这些文件需要保留。

桌面 `探索词典 · 初版.lnk` 为新版入口；原有 `探索词典 · 阅读版.lnk` 和 `探索词典.exe - 快捷方式.lnk` 也已更新到同一程序。正式配置中取词已开启；首次使用按浮窗内的提示完成置顶选择。

部署 2,933 个文件逐一 SHA256 相符；主程序 SHA256：`eba7dc05f820c81830d4d3ca87752d9ed0d6fedcee7d46fd16fd7f95317e1e76`。部署记录见 `artifacts/reading-deployment-v7.json`，以该记录的最终哈希为准。

主界面用于资料管理和完整研读；浮窗用于外部文章划选后的即时解释与追问。最小化主界面继续取词；主界面右上角 × 退出整个应用。浮窗的关闭只收起浮窗，可从主界面“悬浮取词”找回。

1. 进入资料书架，添加 PDF、DOCX、TXT、Markdown、图片，或粘贴正文／保存网页。
2. 阅读原文，选择词语或图片进行解释。问答可选择当前文章或资料库；点击引用查看依据，再跳回原文或原图。
3. 个人笔记与模型回答分别保存。收藏用于回顾；主界面与浮窗共享已保存词条和对话。
4. 在导图页生成文章脉络。树形组织线保持整洁，语义关系在侧栏查看；支持精度、缩放、适应窗口及导出。
5. 在资料信息中识别图片、删除资料。删除同时清理相连版本、笔记、导图和关联取词记录。

模型设置复用已有接口和密钥。图片能力通过实际图像请求检测，不根据模型名称推断。测试时接口配置为 `deepseek-chat`，服务实际响应为 `deepseek-flash`；不将用户口述型号当作已核实的配置。

## 修复与证据边界

全文提取晚于划选记录时，会升级到完整原文，保留词条身份、草稿、笔记及历史引用。旧片段作为历史依据保留，不在书架重复展示；删除完整资料时连同历史版本清理。

PDF 的 ICU 依赖移至 `pymupdf` 子目录，避免抢占 QtWebEngine 渲染子进程使用的 Windows ICU；仅主进程预加载系统 ICU 不足以解决此问题。构建使用清洁缓存，并核查包内代码和部署文件哈希。

实际调用发现 `SSLEOFError / UNEXPECTED_EOF_WHILE_READING`。现按临时断线有限重试，仍严格校验证书；证书验证错误不自动绕过。真实导图调用已观察到断线后的自动重试成功。

导图生成中曾遇到原图复核拒绝和原句不匹配，拒绝记录保留，未用错误图覆盖已有图。图片描述现省略无关留白、背景等信息，并区分图注文字与图形本身。模型生成并不保证每次一次通过；失败会提示，允许重试。

本轮未接管用户真实 WPS／浏览器文档进行鼠标划选。按原交接约定，真实文档的划选弹出体验由用户实机确认；原交接已有普通 DOCX 正文划选验收记录。本轮自动测试不能替代该项现场确认，也不保证所有第三方软件都提供可读取的选区。

PDF 当前支持未加密、200 页以内文件。网页全文提取依赖网页是否提供可读取正文；图片识别与导图生成依赖模型服务可用。
