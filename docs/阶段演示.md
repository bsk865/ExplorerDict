# 探索词典 · 阶段演示

对应版本：1.0.20261025.3。

## 开始前

解压免安装包，双击“探索词典-原生版.exe”。在设置中配置自己的模型服务，选择模型与推理强度。准备一篇允许展示的文章；分享程序时使用干净ZIP，个人资料目录单独保留。

## 演示顺序

1. **发现内容**：打开“发现”，查看新闻和论文，选择来源与最新发布。点击“更新内容”；若来源没有新文章，页面会明确显示“暂无新增或修改”。在“兴趣与来源”展示订阅和兴趣设置。
2. **阅读全文**：查看一条内容，点击“获取全文并加入资料库”，打开资料。也可以导入已准备好的公开PDF。展示文内查找、原文标注和随文笔记。
3. **跨语言阅读**：在本文工具栏打开“翻译”，选择源语言和目标语言，对照查看原文与译文。切换另一篇文章，再返回，展示译文按文章保存。
4. **边读边问**：点击“问本文”，围绕文章提出问题。回答后展开引用，点击回到原句；在资料库问答中可扩大查阅范围。
5. **整理理解**：打开本文导图，查看分支与原文依据，修改节点或补充自己的理解。导出阅读笔记，保留标注、问答和译文。
6. **继续学习**：展示计划与完成记录、城市记忆和主题设置。切换主题后，主界面与浮窗使用相同配色。小窗口保持本版现有布局。

联网来源可能临时不可用，可继续使用已准备的公开资料。模型结果以现场实际回答为准；历史回答和现场生成的回答分别说明。
