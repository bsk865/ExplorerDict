# 内容管理

侧栏“内容管理”可查找文章、笔记、探索对象、问答、计划、主题、导图、阅读记录、标注和未提交草稿。“笔记管理”直接进入阅读笔记，可按所属文章筛选。

选择“问答记录”后，可以搜索当前与先前对话、待继续问题、会话笔记及回答时引用的原文。消息数量包括先前对话。点击“查看内容”在页面内阅读完整记录，点击“返回列表”保留筛选和滚动位置。

每条引用可查看对应原文或笔记；跳转后用顶部返回按钮回到原记录和阅读位置。原资料或笔记已删除时，保留历史引用并在页面内说明；原文版本或位置不一致时要求重新核对。查看和返回不会调用模型。

阅读标注、词语与图片探索、规划记录也在页面内查看。探索记录可回到所属文章及对象，标注可通过来源入口定位原文。

删除前显示具体影响范围。删除对话会清空这组问答、输入草稿与回顾，独立笔记保留；删除主题不会删除其中的文章；删除文章及历史版本则连同其译文、标注、笔记、导图和问答一起移除。
