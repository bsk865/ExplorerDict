# 思维导图

在资料库打开文章，进入“导图”。导图使用当前资料的完整内容，不使用旧词条释义补写文章。

## 选择生成依据

- **正文导图**：研读可提取的正文。文字型 PDF 默认使用此模式，页面原图仍会保留，但不计入这次导图的分析范围。
- **图文导图**：同时研读正文与图片，需要通过实际图片能力检测的模型。扫描 PDF 应使用此模式，避免遗漏无文字页面。

生成先独立阅读并记录原文依据，再依据阅读清单整理草稿，最后对照原文复核，最多三轮纠错。超过8,000字符的正文自动分段，逐段通过后缓存，按原文顺序合并。后续重试复用已通过的分段；连接中断时也保留已完成的阅读与待核对草稿，恢复后仍须通过复核。分段之间不添加未经原文证实的关系。

“重新整理”会清除当前输入对应的分段进度，从原文重新研读；不清空其他资料或其他模型的缓存。重建中断后可继续本次的新进度，不混入旧分段。已有正式导图保留到新结果通过后才替换。

PDF 按文本块提取，避免页边标记穿插正文。引用可容许换行、缩进等空白排版差异，保存时恢复成实际原文片段；改变词语、数字或标点仍会被拒绝。页面原图和通过发现页下载的论文原始 PDF 可供核对。

遇到模型错误合并的跨页引用，会单独回原文定位这些引用，保留独立阅读清单的含义，随后继续逐字核对和语义复核；找不到依据时仍会拒绝。生成期间显示当前分段、阶段、活动条和实际用时，可随时停止。

复核发现有明确编号的信息项遗漏条件、程度或可选性时，只针对这些条目回到完整原文修正，其余清单与划选词保持不变；随后仍重新核对草稿。无法定位的问题继续完整重读。修正中断后可以恢复进度。损坏、引用不符或缺少通过记录的分段缓存会重新生成，不影响其他已通过的分段。

## 查看与导出

画布支持拖动画布、缩放、自适应和层级显示。选择节点或关系后查看其原文依据，并返回阅读页定位。组织树表达整理结构；有原文支持的语义关系单独列出，避免为了连接节点而编造关系。

可导出完整 PNG、SVG 或带节点、关系及引用的 Markdown，不受当前折叠层级限制。技术记录仅保存在本机，不作为日常操作入口。

生成中可以停止或离开页面。新结果通过复核后才替换原有导图；生成失败会显示原因并保留原图及本轮记录。

当前支持自动生成与来源核对，自由编辑节点、拖动节点重新排版尚未提供。真实长论文生成的稳定性仍在改进，最新结果见[开发状态](开发状态.md)。
