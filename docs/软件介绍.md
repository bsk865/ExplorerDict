# 探索词典

探索词典把发现、阅读、理解与整理连接成一个本地学习空间。它从阅读中的一个词、一张图、一个疑问出发，帮助用户保留问题出现的位置，并把随后的理解沉淀到自己的资料库。

## 应用场景

### 课程与自主学习

学习者导入课件、讲义或文字资料，在原文中查找、标注与写笔记。遇到概念时可选词探索，或打开“问本文”边读边问。回答中的引用连接原句，理解完成后可以整理导图，并安排下一次阅读。

### 论文与技术文档研读

用户从公开论文、PDF和技术文章建立主题资料库。文章工具栏提供语言选择与翻译，图片支持缩放和框选理解；多篇资料共同参与问答，帮助梳理相同概念在不同材料中的表达。导图与笔记导出后可继续用于复习或写作。

### 跨平台专题探索

“发现”将科技社区、新闻、科学传播与开放论文放到同一入口。用户选择关注方向，浏览不同来源，收藏值得跟进的内容，并将需要精读的全文加入资料库。来源筛选与最新排序帮助主动安排信息获取方式。

### 跨应用日常积累

在浏览器或其他应用阅读时，浮窗承接划词和上下文。词条保留来源，用户可以先完成短暂理解，再回到主界面整理文章、探索记录与笔记。主题和模型设置由两个入口共同使用。

## 设计理念

**以阅读现场为中心。** 原文、选区、提问与引用保持联系。文章旁的问答减少来回切换，译文和导图随文章保存，让用户下次打开时接着读。

**让知识有来处。** 文章保留来源与版本，回答附引用，导图节点可以查看原文依据。个人笔记和手动补充有自己的标识，便于区分材料与理解。

**把零散探索连成路径。** 从划词到资料、从问题到笔记、从导图到计划，各功能沿用共同的文章与对象关联。学习记录因此可以回看、查找与继续使用。

**保留发现新方向的空间。** 兴趣排序与平台交错共同安排内容，用户还可以直接选择来源、增减订阅和屏蔽关键词，掌握自己的信息入口。

**让软件适应自己的习惯。** 资料存放在本机，用户可选择保存位置、模型服务、问答预算、主题及明暗模式。主界面与浮窗采用一致的视觉语言。

## 功能介绍

| 环节 | 核心功能 | 留下的内容 |
| --- | --- | --- |
| 发现 | 多源订阅、兴趣推荐、最新排序、收藏、链接收集 | 来源和关注线索 |
| 阅读 | 全文接入、PDF/DOCX/文本导入、查找、图片与标注 | 原文、版本与阅读位置 |
| 理解 | 本文与资料库问答、引用定位、图片选区理解、语言翻译 | 对话、依据与所属译文 |
| 整理 | 随文笔记、主题资料库、导图编辑、阅读笔记导出 | 可复用的知识结构 |
| 行动 | 对话式学习计划、日程冲突处理、待办与统计 | 后续安排与完成记录 |
