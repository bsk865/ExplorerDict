# 阅读版 6：窗口与内容重置

2026-10-15。桌面两个探索词典快捷方式均指向阅读版 6。

## 已实施

- 主界面使用独立 Qt WebEngine 无系统标题栏窗口。自定义最小化、最大化/还原、关闭；拖动标题栏移动，右下角调整大小。初始尺寸按屏幕可用区域限制。
- 主界面关闭 = 请求取词组件退出、等待启动中的组件接收退出、停止阅读服务。最小化仍保留悬浮取词。浮窗自己的 × 只隐藏浮窗，由主界面取词入口找回。
- 浮窗使用默认暖纸/赤陶配色，扩大关闭按钮，并接入窗口关闭消息与 Alt+F4。清除历史浮窗位置尺寸，避免沿用异常几何。
- 正式程序没有示例文章入口。两份数据存储的全部阅读内容已清空；仅保留模型设置和密钥等配置。导出、日志、旧浏览器缓存移到不被应用读取的恢复备份。
- 窗口进程和阅读/PDF 服务进程隔离，解决 Qt 系统 ICU 与 PDF 随包 ICU 同名冲突。固定 PySide6 6.10.3。原网页在系统浏览器打开，导出提供保存位置选择。

## 验证与边界

- 231 项浮窗、桥接、启动回归通过；另有内容重置和工作区回归通过。立即关闭时接收器尚未就绪的竞态新增检查通过。
- Windows 实际渲染确认空书架、自定义标题栏、最大化/还原及关闭按钮。offscreen 模式可测行为但无法正确捕获 WebEngine 图像，因此不采用其空白截图作为视觉证据。
- 最终安装版验证 Win32 无系统 caption；打开后立即发关闭消息，主窗口、原生取词及阅读服务全部退出。再次启动后两库文章、关键词/对象、导图、对话/笔记及缓存均为零。
- 最终部署 2932 个文件哈希一致。源码取词组件从项目 app 目录加载；安装版使用 _reading_runtime_v6。
- 未代替用户执行外部文档鼠标划选，也未声称覆盖全部应用。浮窗与主界面双向内容自动同步仍未在本轮完成。浮窗统一的是默认暖纸色，其他主题的实时联动尚未完成。
- 本轮没有复现用户描述的所有界面异常；已修正查到的尺寸、边框、关闭生命周期和启动竞态。实际交互手感仍待用户反馈。
