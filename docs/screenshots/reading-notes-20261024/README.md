# 阅读与笔记导出

这些截图由当前原生窗口在隔离资料目录中离屏渲染，未操作用户的桌面、鼠标或键盘。

- `reading.png`、`reading-narrow.png`：普通与900×620窗口的表格、公式、标注和问答。
- `formula.png`：在文章内放大公式，支持拖动、缩放和返回原文，无独立弹窗。
- `translation.png`：文章工具栏中的翻译，译文属于当前文章，侧栏没有翻译分区。
- `versions.png`：按创建顺序列出文章版本，使用可读版本名称。
- `export.png`：应用自身的文件浏览面板，保存本文章的阅读笔记。

文章、公式、问题、回答、译文和笔记均为自编展示内容；没有调用模型，不作为实际翻译或问答质量的证据。文件面板中的路径是临时隔离目录，不含个人资料或密钥。

生成脚本：[`tools/capture_reading_notes.py`](../../../tools/capture_reading_notes.py)。对应导出：[阅读笔记示例](../../examples/阅读笔记.md)。
