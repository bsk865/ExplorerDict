# 保存的问答与原文定位

- `list.png`：在内容管理中搜索先前问答及引用。
- `conversation.png`、`conversation-narrow.png`：完整对话的普通窗口与900×620窗口。
- `annotation.png`：页内查看标注与所属原文。

截图由当前原生窗口离屏渲染，使用隔离目录中的自编文章、问题、回答与引用，没有调用模型、启动取词监听或操作用户桌面。流程实际执行了查看历史、引用定位、返回恢复和标注查看；这些演示内容不作为模型质量的证据。

生成脚本：[capture_content_records.py](../../../tools/capture_content_records.py)。
