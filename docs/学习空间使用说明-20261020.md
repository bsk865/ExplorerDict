# 学习空间

从桌面“探索词典 · 初版”进入。主程序为 `探索词典-初版1.exe`。

## 主题资料库

新建主题后，使用“整理文章”选择资料。点击主题进入，再点文章开始阅读。同一篇文章可以放入多个主题，原文只保存一份。删除主题不会删除文章；未分类文章可在“未分类”中找到。

## 心得与笔记

阅读时打开“笔记”，记录整篇心得；选中一段文字后点“记笔记”，可以连同引用保存。笔记自动保存，也可以手动保存。旧词条笔记仍可查看。笔记保留对应原文版本，旧版本笔记不会被静默挂到新版段落。

## 资料库问答

“选择资料”可按主题勾选文章。“包含我的笔记”决定是否检索个人心得，默认只用原文。“查找依据”在本机预览相关片段；发送问题时才调用已配置的模型。

“比较阅读”对所选2至12篇文章整理研究对象、方法、结论及待核对问题。比较基于检索或抽样片段，不代表完整审阅全部文献。点击引用回到原文或对应笔记。

正文引用的“在原文中定位”会打开所属文章、高亮引用内容，并显示引用开头；富文本也使用对应字符位置。若原文已变化，保留回答时的片段，提示重新核对，不把旧位置当成当前原句。

回答下方的“整理为笔记”会打开可编辑草稿。检查后选择归属文章并确认保存，笔记标记为小探整理并保留引用；未经确认的聊天回答不会自动入库。

## 今日与计划

今日显示时间、天气、当天安排和继续阅读入口。天气需先选择城市；不读取设备定位，网络异常时会标记旧数据或不可用。

计划支持全部列表和周视图。点击任务可以修改日期、延期、拆分或删除。完成任务后勾选，取消勾选可恢复。带明确时间的未完成任务会检查冲突。

“请小探规划”中写明目标，选择可用日期、每日时段、分钟上限和相关资料。小探可能先提出必要问题；可执行的计划通过时间校验后直接保存。规划记录中可以撤销整批添加；已经修改或完成的任务需逐项调整。

## 探索统计

统计包括心得、完成任务、主动标记读完的文章、最近七天打开文章的趋势和各主题进度。打开文章不等于读完或掌握；同一文章每天只计一次打开记录。记录从功能启用后开始，不补造过去的阅读历史。

## 当前范围

- 资料、笔记、计划和统计保存在本机，模型请求使用现有API配置。
- 2026-10-21 起内置 multilingual-e5-small 本地向量模型，使用语义与关键词混合检索。导入和编辑后后台增量索引；文章、笔记删除后不再检索对应向量。向量计算不发送资料到外部；问答生成仍使用已配置 API。
- 主题资料库和资料库问答内可打开“知识索引”，查看状态、片段及来源，更新或重建索引。原文、笔记和标注不会因重建而删除。笔记仅在问答勾选“包含我的笔记”时参与召回。
- 语义片段约240字符、重叠40字符，按模型上限继续拆分；关键词索引保留原有1400/180切块。引用保留文章、版本、段落及原始偏移。索引失败时显示错误并可重建，语义检索异常时回退关键词。
- 当前是文字语义 RAG，未加入独立重排模型、扫描件自动OCR、跨资料图文统一向量检索。英文跨语言查中文资料的初步实测不稳定，建议与资料使用相同语言提问。已有引用编号及版本检查不是逐句事实核验，质量测试是小规模功能验收，不代表全面召回率或回答忠实度评测。
- 日程保存在本应用，尚未接入外部日历或关闭程序后的系统提醒。
- 图片预算不足会提示调整，不会仅因图片预留而清空或结束现有对话。模型多模态支持仍以设置中的能力检测为准。
