# 阅读笔记

在文章的“文章操作”或“资料信息”中选择“导出笔记”，保存为 Markdown 文件。导出包含原文、原文标注、对象笔记、当前与先前问答及其引用、随文心得、待继续的问题和本文译文；尚未保存为正式笔记的心得以“草稿”标明，未完成译文保留状态。

导出使用当前文章自己的资料，不合并其他文章或历史版本的笔记与译文。文章改名后使用新标题。图片内嵌在文件中；表格和公式保留安全 HTML 与 MathML，显示效果取决于所用 Markdown 阅读器是否支持这些格式。

文章中的长公式会随阅读宽度缩小，点击公式可以在文章内放大、拖动查看，点击“返回原文”继续阅读。复制带公式的原文时保留数学文本与 MathML。

[导出示例](examples/阅读笔记.md)中的内容均为自编演示资料，不是实际模型生成结果。[截图来源](screenshots/reading-notes-20261024/README.md)。
