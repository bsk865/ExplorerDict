# 操作演示脚本

## 准备

运行当前Windows版本，准备允许展示的文章和公开资料，在设置中选择自己的模型服务。演示中的文章、问题与引用保持对应，界面中收起密钥。

## 从内容到理解

1. 在“发现”浏览不同平台，切换来源和最新发布，查看一篇新闻或论文。
2. 获取全文并加入资料库，打开原文，查找、标注并写一条笔记。
3. 在文章工具栏选择翻译语言，对照阅读，切换文章后恢复各自译文。
4. 打开“问本文”，提出问题，展开引用并返回原句。
5. 查看导图的分支与依据，修改节点或补充关系，导出阅读笔记。
6. 安排后续学习，展示待办与完成记录，以及主界面与浮窗的主题联动。

## 展示开发过程

沿[开发过程](开发过程.md)选择一条功能链，展示原始需求、问题反馈、修改方案与相应提交。资料问答、请求管理和学习规划均有完整记录，可结合代码说明数据如何流动、状态如何保存。

## 结束

展示下载入口、使用指南和源码运行方式。演示视频由项目作者制作。
